# AdCut Web foundation

Standalone React/TypeScript SPA. Run all commands from `web/`; use Node 24.15+ (Node 24 LTS recommended) and npm. The package engine range also permits supported Node 22 and 26 releases. No Flutter sources are imported or built.

## Run and verify

```sh
npm ci
npm run dev
npm run format:check
npm run lint
npm run typecheck
npm test -- --run
```

Set `VITE_API_BASE_URL` in the environment or copy `.env.example` to `.env.local` before `npm run build`. Production builds deliberately fail when this value is absent or invalid, including builds with a custom mode. Development defaults to `http://localhost:8000`. The deployed API is `https://video-studio-prod-production.up.railway.app`.

`VITE_*` values are public and appear in the browser bundle: never add tokens, provider keys, storage credentials, or other secrets. Only the API URL is consumed by the application configuration module.

```sh
npx playwright install chromium
npm run test:e2e
```

Playwright builds and serves the production bundle with a local public API URL; the placeholder shell does not make requests. Its checks cover client navigation, direct nested navigation, and refresh. MSW handles test-only requests in Vitest and fails unexpected requests. It is never started in the application.

## Boundaries

- `src/app`: application composition, router, query client, and error boundaries.
- `src/routes`: TanStack file routes; compose features here, keep business logic elsewhere.
- `src/core`: shared config, API, auth, design, upload, and polling boundaries. Core cannot import features or app/routes.
- `src/features`: onboarding, projects, workspace, cut-review, adjust, variants, and export. Features use core and never app/routes.
- `src/test`: isolated render helpers and MSW server. Tests render the same `AppProviders` as `src/main.tsx`.
- `e2e`: browser journeys against the production bundle.

`@/*` resolves to `src/*` in the compiler, Vite, and Vitest. ESLint checks inward dependency boundaries. `src/routeTree.gen.ts` is generated by the TanStack router plugin or `npm run typecheck`; commit its output, but do not edit it manually. Styling uses CSS Modules and semantic global tokens. The current token set is a minimal foundation, to be extended by the design-system ticket.

## Vercel

Select `web` as the project root and set `VITE_API_BASE_URL`. The checked-in config selects Vite, builds `dist`, rewrites deep links to the SPA entry, and applies static security headers. Browser tests use Vite preview's SPA fallback; Vercel rewrite/header behavior must also be smoke-tested on an actual deployment.

The foundation CSP restricts framing, embedded objects, and base URLs. Expand it to a complete source policy once the exact API and object-storage origins are settled; do not introduce wildcard media or connection origins. Deployment and production CORS configuration belong to later tickets.
